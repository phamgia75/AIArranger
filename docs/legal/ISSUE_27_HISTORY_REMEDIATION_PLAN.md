## 7. Backup and recovery (before any C step)

1. **Freeze:** announce a window; no pushes; PR #38 merged or closed.
2. **Full backup, kept private and offline.** It contains the restricted files, so it is never pushed anywhere:
   ```sh
   git clone --mirror git@github.com:<owner>/AIArranger.git AIArranger-backup.git
   git -C AIArranger-backup.git bundle create ../AIArranger-pre-purge.bundle --all
   git -C AIArranger-backup.git show-ref > ../refs-before.txt
   git bundle verify ../AIArranger-pre-purge.bundle
   ```
   Store the bundle on encrypted local storage, and record its SHA-256 in the execution log.
